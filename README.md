# 3D Portfolio — DevOps × Game Development

Static portfolio built with:
- HTML
- CSS
- JavaScript
- Three.js (ES module loaded from jsDelivr)

## Run
Because the JavaScript uses an ES module, run it through a local web server.

For example:
`python -m http.server 8000`

Then open:
`http://localhost:8000`

## Personalise
Replace:
- `Your Name`
- `YN`
- `your.email@example.com`
- LinkedIn URL
- GitHub URL

Add real project links/screenshots when ready.

## Three.js
The background contains an animated 3D wireframe object, orbiting rings and a particle field. Mouse movement subtly changes the scene.
